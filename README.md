# PUREVITANUTRITION
Projet de gestion commerciale PURE VITA.

Modules : stock, POS/ventes, clients, fournisseurs/achats, finance, documents, rapports, utilisateurs, magasins, sécurité et journal.

## Installation
1. Garder `logo-pure-vita.png` dans le même dossier.
2. Dans `app.js`, remplacer les deux valeurs `VOTRE_URL_SUPABASE` et `VOTRE_CLE_PUBLISHABLE_SUPABASE` par les informations du projet Supabase.
3. Exécuter `supabase.sql` après vérification.
4. Déployer sur GitHub Pages.

Ne jamais mettre une clé `service_role` ou secrète dans le frontend.
